薛定谔方程是量子力学的基本方程，描述量子态（波函数）如何随时间演化。它类似于经典力学中的牛顿第二定律，但适用于微观粒子。含时薛定谔方程为：

\[
i\hbar \frac{\partial \Psi}{\partial t} = \
\hat{H} \Psi
\]

其中 \(\hat{H}\) 是哈密顿算符（总能量算符），\(\Psi\) 是波函数。定态情况下可化为定态薛定谔方程：

\[
\hat{H}\psi = E\psi
\]

**一维无限深势阱**（宽度为 \(a\)，势阱内势能为0，外部为无穷大）的能级为：

\[
E_n = \frac{n^2 \pi^2 \hbar^2}{2ma^2}, \quad n = 1, 2, 3, \dots
\]

其中 \(m\) 是粒子质量，\(a\) 是势阱宽度，\(\hbar\) 是约化普朗克常数。对应的波函数为：

\[
\psi_n(x) = \sqrt{\frac{2}{a}} \sin\left(\frac{n\pi x}{a}\right), \quad 0 < x < a
\]

能级是离散的，且最低能量 \(E_1 > 0\)（零点能不为零），这是量子力学与经典力学的重要区别。
