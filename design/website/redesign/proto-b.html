    常见问题

    装之前常问的

    要花钱吗？

    软件免费。语音识别和回答用你自己的 Key，按服务商的价格从你自己的账户扣。火山引擎每个识别版本送 20 小时，阿里百炼每个模型送 100 万 Token 的免费额度，以服务商当前的页面为准。

    为什么装好后没有快捷键？

    每台 Mac 的键盘不一样，顺手的键也不一样，所以默认不设。在「设置 → 快捷键」里选一个平时少用的键，比如右 Option、右 Command。

    第一次打开提示「无法验证」怎么办？

    这一版有开发者签名，但还没经过苹果公证。到「系统设置 → 隐私与安全性」底部点「仍要打开」，只需要一次。

    Intel 芯片的 Mac 能用吗？

    不能。需要 Apple 芯片，macOS 14 或更新。

    截图会存下来吗？

    会存在你自己的 Mac 上，回头在「历史」页能看到当时的画面；不会上传到别处，在「历史」页能删。

    回答面板会打断我正在做的事吗？

    不会。面板出现在屏幕右上角，不把你正在用的窗口挤到后面，正在打字的地方还在原处。

    能换别的模型吗？

    回答目前支持 DeepSeek 和阿里百炼千问，语音识别用火山引擎（豆包）。

    隐私说明

    Ask Free 没有自己的服务器。只有你按下提问键、说完松开的那一刻，录音和截图才发出去，而且直接发给你自己选的服务商；问过的问题只存在你的 Mac 上。

    草稿：按 v1.0.1 代码里真实的去向写成，还没经过法律审核。

    留在你电脑上的

    • API Key：存在 macOS 钥匙串里，不写进普通文件。
    • 设置：在 ~/.config/askfree/，只有你的账户能读。
    • 问答历史：文字在 history.jsonl，发给模型的截图、回答里找到的图的缩略图在 history-images/，都在同一个文件夹里，在应用的「历史」页能看、能删。

    什么时候发出去

    只在你按住（或轻点）自己设的提问键、说完的时候。平时不录音、不截屏，菜单栏图标也不会一直监听。

    用「只提问，不看屏幕」那个键时不截屏，只发语音转出来的文字。

    发给谁、发什么

    用途发给发什么
    语音识别火山引擎（豆包）这一次的录音
    回答问题DeepSeek 或阿里百炼千问，你在「模型」页选的那家识别出的文字；看屏幕问时加上这一刻的截图；追问时带上这个话题前几轮的问答
    回答配图DuckDuckGo 图片搜索一个找图用的搜索词，不含截图和录音。设置里关掉「联网回答附图」就不发

    用的是你自己的 Key，这些服务商按各自的隐私政策处理收到的内容。

    我们不做的

    • 不需要注册账号，也没有登录。
    • 没有使用统计、没有崩溃上报。
    • 没有中间服务器：语音和问题不经过我们。
    • 没有自动更新：新版本在网站和 GitHub 上下载。

    本网站

    不用 Cookie，不做访问统计。下载文件放在 GitHub，点下载时由 GitHub 提供文件。

    怎么删掉

    1. 「历史」页右键一条删除，或者全部清空。
    2. 退出 Ask Free，删掉 ~/.config/askfree/ 文件夹。
    3. 打开「钥匙串访问」，搜索 askfree，删掉里面的 Key。
