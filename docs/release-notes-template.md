## 下载

| 系统 | 文件 |
| --- | --- |
| Mac · Apple 芯片（M1/M2/M3/M4）和 Intel 芯片通用 · macOS 14 或更新 | `AskFree-{{VERSION}}.dmg` |
| 同上，压缩包 | `AskFree-{{VERSION}}.zip` |

第一次装：打开 dmg，把 **Ask Free** 拖到旁边的「应用程序」文件夹，再从「应用程序」里打开。别在 dmg 窗口或「下载」文件夹里直接打开：那样系统会把它放到临时位置运行，给过的权限下次就不认了。

这个版本有 Developer ID 签名，还没经过苹果公证：第一次打开如果提示无法验证，到「系统设置 → 隐私与安全性」底部点「仍要打开」。

## 从旧版升级

1. 点菜单栏的 Ask Free 图标，选「退出 Ask Free」。
2. 打开新的 dmg，把 **Ask Free** 拖进「应用程序」，提示已有同名项目时选「替换」。设置、历史和 API Key 都还在。
3. 【待填：要不要重新授权。签名证书没换写「辅助功能、屏幕录制、麦克风权限不用重给」；要重给就写清是哪一项、在 Ask Free 的哪一页点什么】
