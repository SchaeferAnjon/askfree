Ask Free 1.2.0：Intel 芯片的 Mac 也能用了；从这一版起有新版本会自动下载，提示你重启就装好。

## 下载

| 系统 | 文件 |
| --- | --- |
| Mac · Apple 芯片（M1/M2/M3/M4）和 Intel 芯片通用 · macOS 14 或更新 | `AskFree-1.2.0.dmg` |
| 同上，压缩包 | `AskFree-1.2.0.zip` |

第一次装：打开 dmg，把 **Ask Free** 拖到旁边的「应用程序」文件夹，再从「应用程序」里打开。别在 dmg 窗口或「下载」文件夹里直接打开：那样系统会把它放到临时位置运行，给过的权限下次就不认了。

Ask Free 有 Developer ID 签名，没有经过苹果公证：第一次打开如果提示无法验证，到「系统设置 → 隐私与安全性」底部点「仍要打开」。

## 从旧版升级

1. 点菜单栏的 Ask Free 图标，选「退出 Ask Free」。
2. 打开新的 dmg，把 **Ask Free** 拖进「应用程序」，提示已有同名项目时选「替换」。设置、历史和 API Key 都还在。
3. 签名证书没换：辅助功能、屏幕录制、麦克风权限不用重给。

这是最后一次要手动升级：1.2.0 起，有新版本时 Ask Free 自己在后台下好，菜单栏里出「重启更新」。

## 这一版改了什么

**安装和更新**
- 一个安装包同时支持 Apple 芯片和 Intel 芯片的 Mac。
- 改成 dmg 安装：打开后把 Ask Free 拖进「应用程序」就装好。
- 自动更新：每 6 小时查一次新版本，后台下好、核对签名后提示重启更新；不点的话，下次退出时装上。在「通用 → 更新」能关，也能点「检查更新」马上查。

**隐私**
- 新加「匿名使用统计」：我们会给前 100 位用户免费额度，所以需要统计有多少人在用。统计是匿名的。欢迎引导里（老用户在第一次打开主窗口时）问你一次，同意了才每天发一次随机编号、版本号、系统和芯片、用会员还是自带 Key、界面语言；不用了就什么都不发。在「通用 → 隐私」随时能改。
- 新加「共享屏幕时隐藏回答面板」，默认打开：开会共享屏幕、录屏或截图时，回答面板、打字框和录音浮窗不进画面。
- 回答里的链接和找到的图只打开网页（https）和邮箱地址，别的链接点了不开。
- 屏幕录制的授权说明和「回答方式」页写清：截图会存进这台 Mac 上的历史；配图只把一个搜索词发给 DuckDuckGo。

**主窗口**
- 「关于」页加了官网、我们的其他软件、联系邮箱、打开日志，列出每一项发给谁、发什么；版本信息能一键复制，写信报问题时贴上。
- 屏幕录制是打开 Ask Free 以后才给的：「权限」页给「重新打开 Ask Free」按钮，点一下就生效。
- 「通用」里加「再走一遍引导」。
- 报错卡上的网络错误只写一句说明，不再贴出一整段错误代码。

**回答卡**
- 用英文问就用英文答（以前常拿中文答英文问题）。
- 追问时，折起来的上一轮不再露出代码的反引号。
- 截图慢了半拍时不再白等 2.5 秒后只发文字。

**快捷键**
- App 菜单加「关于 Ask Free」和「设置… ⌘,」；⌘1 到 ⌘9 换页，侧栏里按 ↑↓ 换页，「历史」页 ⌘F 搜索。

**辅助功能**
- 旁白能读出开关、选中的项和按钮；系统开了「减少动态效果」时，界面不再做滑动和晃动的动画。
