Ask Free 1.3.0：不用再自己填 Key 了，新加会员，前 100 位新用户免费问 30 个问题；回答里的公式和代码排得像样；「历史」页能把一天问过的问题整理成图文笔记。

## 下载

| 系统 | 文件 |
| --- | --- |
| Mac · Apple 芯片（M1/M2/M3/M4）和 Intel 芯片通用 · macOS 14 或更新 | `AskFree-1.3.0.dmg` |
| 同上，压缩包 | `AskFree-1.3.0.zip` |

第一次装：打开 dmg，把 **Ask Free** 拖到旁边的「应用程序」文件夹，再从「应用程序」里打开。别在 dmg 窗口或「下载」文件夹里直接打开：那样系统会把它放到临时位置运行，给过的权限下次就不认了。

Ask Free 有 Developer ID 签名，没有经过苹果公证：第一次打开如果提示无法验证，到「系统设置 → 隐私与安全性」底部点「仍要打开」。

## 从旧版升级

- 用的是 1.2.0：不用动手。Ask Free 会在后台下好 1.3.0，菜单栏里出「重启更新」，点一下就装好；不点的话，下次退出时装上。也可以在「通用 → 更新」点「检查更新」马上查。
- 用的是 1.1.0 或更早：这些版本没有自动更新，手动换一次。
  1. 点菜单栏的 Ask Free 图标，选「退出 Ask Free」。
  2. 打开新的 dmg，把 **Ask Free** 拖进「应用程序」，提示已有同名项目时选「替换」。设置、历史和 API Key 都还在。
- 签名证书没换：辅助功能、屏幕录制、麦克风权限不用重给。

## 这一版改了什么

**会员（新）**
- 用法二选一：会员不用填任何 Key；自带 API Key 照旧，永久免费、不限次数。欢迎引导里选，之后在主窗口「会员」页随时能换。
- 前 100 位新用户每台 Mac 免费问 30 个问题，不过期。第一次用会员提问、打开「会员」页或在引导里点「领取免费试用」时才领。
- 订阅：每月 ¥9.9 或 $1.99，每年 ¥99 或 $19.9，自动续费，随时取消。人民币也能用微信一次买 1 个月或 1 年，不自动续费。
- 买了以后发一个授权码，在另一台 Mac 的「会员」页输入就行，一个授权码最多用在 2 台 Mac 上。「管理订阅」在「会员」页，能换卡、改月付年付、取消、看发票。
- 会员模式下，录音、问题文字和截图发到我们的服务器，服务器转给火山引擎（语音识别）和 DeepSeek（回答、联网搜索）。服务器不存录音、截图、问题和回答。「会员」页和 README 的隐私说明里写着发给谁、发什么。

**回答卡和历史**
- 回答里的数学公式像书上那样排；代码分成一块一块，按语言着色，每块有「复制」按钮。复制整个回答时，代码块原样保留。
- 放不下的代码和公式在块里横向滚动，右端渐隐提示还能往右。

**历史：每天的图文笔记（新）**
- 「历史」页点「今天的笔记」，AI 把这一天问过的问题整理成一页图文笔记：小结，加上每个问题的截图和回答要点，左边有能收起的目录。每天旁边的「笔记」能看以前的。
- 能点「用浏览器打开」，或「导出 PDF」（A4 浅色，截图占满正文宽，截图和代码块不会被分页切开）。
- 能勾几个问题导进 Anki（要先装 AnkiConnect 并打开 Anki）。导完告诉你加了几张、几张已经有了；Anki 没开着会说明，勾选还留着。
- 整理时，这一天的问题和回答文字（不含截图）发给你配置的模型；会员模式发到我们的服务器，整理一次算一个问题。删历史时，那一天的笔记一起删。
