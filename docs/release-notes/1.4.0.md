Ask Free 1.4.0：指着一个词问，AI 认得出是哪个词；语音听错了会照着屏幕改正；指着代码问，按讲代码的方式讲透；回答更有见解。不再做匿名使用统计，也不再送免费试用。

## 下载

| 系统 | 文件 |
| --- | --- |
| Mac · Apple 芯片（M1/M2/M3/M4）和 Intel 芯片通用 · macOS 14 或更新 | `AskFree-1.4.0.dmg` |
| 同上，压缩包 | `AskFree-1.4.0.zip` |

第一次装：打开 dmg，把 **Ask Free** 拖到旁边的「应用程序」文件夹，再从「应用程序」里打开。别在 dmg 窗口或「下载」文件夹里直接打开：那样系统会把它放到临时位置运行，给过的权限下次就不认了。

Ask Free 有 Developer ID 签名，没有经过苹果公证：第一次打开如果提示无法验证，到「系统设置 → 隐私与安全性」底部点「仍要打开」。

## 从旧版升级

- 用的是 1.2.0 或 1.3.0：不用动手。Ask Free 会在后台下好 1.4.0，菜单栏里出「重启更新」，点一下就装好；不点的话，下次退出时装上。也可以在「通用 → 更新」点「检查更新」马上查。
- 用的是 1.1.0 或更早：这些版本没有自动更新，手动换一次。
  1. 点菜单栏的 Ask Free 图标，选「退出 Ask Free」。
  2. 打开新的 dmg，把 **Ask Free** 拖进「应用程序」，提示已有同名项目时选「替换」。设置、历史和 API Key 都还在。
- 签名证书没换：辅助功能、屏幕录制、麦克风权限不用重给。

## 这一版改了什么

**指着一个词问**
- 按下提问键的那一刻，Ask Free 在你的 Mac 上认出指针周围的字（用的是 macOS 自带的文字识别，不联网），挑出指针正下方的那个词，连同它所在的那一行用文字告诉 AI。截图上的红框只框住这个词，不再框住一片。
- 先选中一段文字再问，就按选中的那段答。
- 认不出字的地方（图片、视频画面），照旧框住指针周围一片。

**语音听错了会改正**
- AI 知道问题是语音识别出来的，会结合屏幕上的字，按你真正想问的来答。它确定有词听错时，回答卡上的问题换成改正后的，原话留一行小字「听成「…」」。比如说「伊欧艾尔是什么意思」，卡上变成「EOL 是什么意思」。
- 识别语音时，把指针附近的英文词和这个话题前几轮的问答一起交给火山引擎，专有名词更容易认对。自带 Key 和会员都有。

**讲代码**
- 指着代码、报错或终端里的命令问，或者在编辑器、终端里问：按讲代码的方式答，错的写法和改好的写法并排给出，再把这一行拆开讲。

**回答**
- 回答的要求重写了：去掉字数上限和一长串限制，回答会讲到言外之意、容易混的地方和常见的坑。回答长度的上限是原来的 2.5 倍，讲代码时是 4 倍。
- 开了思考时，「模型在先想一下」这行提示一出字就消失，不再一直挂着。

**会员和隐私**
- 去掉匿名使用统计：第一次打开不再问，「通用」里的开关也没有了，Ask Free 不再每天报到。
- 不再送免费试用。会员照常卖：每月 ¥9.9 或 $1.99，每年 ¥99 或 $19.9，也能用微信一次买；以前领过试用、还没用完的照常能用。
- 发给谁、发什么多了几样：识别时多发指针附近的英文词和前几轮问答；回答时多发本机认出的指针附近的字和你选中的文字。「关于」页和官网隐私说明写着。
