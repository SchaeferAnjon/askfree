Ask Free 1.5.0：送进 Anki 的卡换了新样子，默认放进「知识」牌组，和 ChatCards、GetNewWord 用同一种卡；设置里多了「Anki」页，一项项查 Anki 连没连上；「打开 Anki」能认出现在的 Anki 了。

## 下载

| 系统 | 文件 |
| --- | --- |
| Mac · Apple 芯片（M1/M2/M3/M4）和 Intel 芯片通用 · macOS 14 或更新 | `AskFree-1.5.0.dmg` |
| 同上，压缩包 | `AskFree-1.5.0.zip` |

第一次装：打开 dmg，把 **Ask Free** 拖到旁边的「应用程序」文件夹，再从「应用程序」里打开。别在 dmg 窗口或「下载」文件夹里直接打开：那样系统会把它放到临时位置运行，给过的权限下次就不认了。

Ask Free 有 Developer ID 签名，没有经过苹果公证：第一次打开如果提示无法验证，到「系统设置 → 隐私与安全性」底部点「仍要打开」。

## 从旧版升级

- 用的是 1.2.0 到 1.4.0：不用动手。Ask Free 会在后台下好 1.5.0，菜单栏里出「重启更新」，点一下就装好；不点的话，下次退出时装上。也可以在「通用 → 更新」点「检查更新」马上查。
- 用的是 1.1.0 或更早：这些版本没有自动更新，手动换一次。
  1. 点菜单栏的 Ask Free 图标，选「退出 Ask Free」。
  2. 打开新的 dmg，把 **Ask Free** 拖进「应用程序」，提示已有同名项目时选「替换」。设置、历史和 API Key 都还在。
- 签名证书没换：辅助功能、屏幕录制、麦克风权限不用重给。

## 这一版改了什么

**送进 Anki 的卡**
- 卡换成一张纸的样子：正面是问题，看屏幕问的那一屏放在问题下面；翻过来问题变灰、位置不动，下面是一句答案，其余要点是补充，出处压在纸底。深色模式跟着 Anki 换；窗口窄到手机那么宽时，纸铺满屏幕。
- 卡用的是笔记类型「学习卡 · 问答」，和 ChatCards、GetNewWord 的问答卡同一个，三个软件送的卡在 Anki 里长得一样。你在 Anki 里改过它的模板，Ask Free 会先问「换成新样子 / 留着我改的」，不悄悄覆盖。
- 问法一样的两个问题（比如都是「这是什么意思？」）各成一张卡，不再被当成重复。

**牌组**
- 卡片默认放进「知识」牌组（以前是「Ask Free」），每张带「来自::Ask_Free」标签，按来源找卡用标签。底栏能选你在 Anki 里自己建的「知识::…」；设置里能改默认牌组的名字，在 Anki 里改了名也跟得上。
- 「Ask Free」牌组里有以前送的卡：第一次送卡前问一次「移到「知识」/ 留着」，只问这一次。移过去复习记录不变，空了的「Ask Free」牌组删掉。以前的卡也换上新样子（模板没被你改过的话）。

**送卡**
- 按钮「导入 Anki」改叫「送进 Anki」。底栏写「已选 3 / 5 个」，送过的问题前面是绿点和「已在 Anki」，都送过以后换成「在 Anki 里看」。
- 送完、Anki 没开、连不上 AnkiConnect 插件，都在底部正中出提示条，各带一个按钮：「在 Anki 里看」只列这次送的卡；「打开 Anki 再送」打开 Anki，连上就接着送；「怎么装」到设置里的「Anki」页。
- 设置里新加「Anki」页：Anki 桌面版、AnkiConnect 插件、Anki 开没开三项每 2 秒自己查一次，缺哪一步就给哪一步的按钮（下载 Anki、复制插件编号、打开 Anki）。

**修复**
- 「打开 Anki」认不出现在的 Anki（它换了程序标识），以前会把你带到下载页；现在直接打开。
- Anki 存截图时如果换了文件名，卡片里也用它换过的名字，截图不会显示不出来。
- 带按钮的提示条，旁白也能点到按钮。

数据的去向没变：送进 Anki 的卡只经过 Anki 在本机开的 AnkiConnect 接口（127.0.0.1），不经过网络。
