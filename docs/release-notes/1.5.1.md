Ask Free 1.5.1：回答时面板不再上下抽；钉住以后点外面缩成右上角的小框，不会自己消失，也能选一直展开；历史页里翻到一条，能在底下接着问。

## 下载

| 系统 | 文件 |
| --- | --- |
| Mac · Apple 芯片（M1/M2/M3/M4）和 Intel 芯片通用 · macOS 14 或更新 | `AskFree-1.5.1.dmg` |
| 同上，压缩包 | `AskFree-1.5.1.zip` |

第一次装：打开 dmg，把 **Ask Free** 拖到旁边的「应用程序」文件夹，再从「应用程序」里打开。别在 dmg 窗口或「下载」文件夹里直接打开：那样系统会把它放到临时位置运行，给过的权限下次就不认了。

Ask Free 有 Developer ID 签名，没有经过苹果公证：第一次打开如果提示无法验证，到「系统设置 → 隐私与安全性」底部点「仍要打开」。

## 从旧版升级

- 用的是 1.2.0 到 1.5.0：不用动手。Ask Free 会在后台下好 1.5.1，菜单栏里出「重启更新」，点一下就装好；不点的话，下次退出时装上。也可以在「通用 → 更新」点「检查更新」马上查。
- 用的是 1.1.0 或更早：这些版本没有自动更新，手动换一次。
  1. 点菜单栏的 Ask Free 图标，选「退出 Ask Free」。
  2. 打开新的 dmg，把 **Ask Free** 拖进「应用程序」，提示已有同名项目时选「替换」。设置、历史和 API Key 都还在。
- 签名证书没换：辅助功能、屏幕录制、麦克风权限不用重给。

## 这一版改了什么

**回答面板**
- 回答时面板不再上下抽。以前面板每长一截，状态条和底栏会被切掉、正文整块往上顶一下再落回；现在面板只往下长，每一截滑过去，状态条和正文不动。
- 联网找到的图等回答出完再放出来，出字时不再跟着字一行行往下挪。

**钉住**
- 钉住的意思改成「不会自己消失」：点外面，面板缩成右上角的小框，鼠标指上去展开，移开再缩。没钉住的小框和以前一样，4 秒不动就淡出。
- 钉住时图钉左边多一颗按钮：四角往里收是「点外面缩成小框」，点一下换成四角往外推、带灰底的「一直展开」，点外面也不缩。选的会记住，下次钉住还是它。

**历史页里接着聊**
- 「历史」页详情最底下多了输入框：翻到一条，打字回车，就接着这一条问下去（⇧回车换行）。回答一段段出在页面里，存进同一条历史，列表里的轮数加一。
- 出字时发送键变成「停下」，已经出来的字会存下。
- 接着聊不看屏幕：发给模型的是你打的字和这一条前面几轮的问答文字，不含截图和录音。用的是你在「语音与模型」页选的那一家；用会员时一问算一个问题。

数据的去向多了一条：在历史页接着问时，你打的字和这一条前面几轮的问答文字发给你选的模型（会员模式是我们的后台），只在你按回车发送时发出去。官网的隐私说明已经写上。
