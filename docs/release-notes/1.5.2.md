Ask Free 1.5.2 修好 1.5.1 带进来的一个问题：按提问键以后有时看不到回答面板，其实已经答了，再按一次才发现是「第 2 问」。

## 下载

| 系统 | 文件 |
| --- | --- |
| Mac · Apple 芯片（M1/M2/M3/M4）和 Intel 芯片通用 · macOS 14 或更新 | `AskFree-1.5.2.dmg` |
| 同上，压缩包 | `AskFree-1.5.2.zip` |

第一次装：打开 dmg，把 **Ask Free** 拖到旁边的「应用程序」文件夹，再从「应用程序」里打开。别在 dmg 窗口或「下载」文件夹里直接打开：那样系统会把它放到临时位置运行，给过的权限下次就不认了。

Ask Free 有 Developer ID 签名，没有经过苹果公证：第一次打开如果提示无法验证，到「系统设置 → 隐私与安全性」底部点「仍要打开」。

## 从旧版升级

- 用的是 1.2.0 到 1.5.1：不用动手。Ask Free 会在后台下好 1.5.2，菜单栏里出「重启更新」，点一下就装好；不点的话，下次退出时装上。也可以在「通用 → 更新」点「检查更新」马上查。
- 用的是 1.1.0 或更早：这些版本没有自动更新，手动换一次。
  1. 点菜单栏的 Ask Free 图标，选「退出 Ask Free」。
  2. 打开新的 dmg，把 **Ask Free** 拖进「应用程序」，提示已有同名项目时选「替换」。设置、历史和 API Key 都还在。
- 签名证书没换：辅助功能、屏幕录制、麦克风权限不用重给。

## 这一版改了什么

**修复**
- 按提问键以后有时没有弹出回答面板。其实问题已经发出去、也答完了，只是面板停在了屏幕右边外面；再按一次提问键，面板回来，显示的已经是「第 2 问」。原因是 1.5.1 起面板高度能当场量准，面板刚开始从屏幕右边滑进来，就按它在半路上的位置改了一次高度，于是整块停在屏幕外。现在面板的位置一律按屏幕右上角算，不管它此刻滑到哪。
- 1.5.1 的其他改动都保留：回答时面板不上下抽、钉住后点外面缩成小框、历史页里接着聊。

数据的去向没变。
