常见问题

装之前常问的

要花钱吗？

软件免费。语音识别和回答用你自己的 Key，按服务商的价格从你自己的账户扣。火山引擎每个识别版本送 20 小时，阿里百炼每个模型送 100 万 Token 的免费额度，以服务商当前的页面为准。免费额度用完以后，一次看屏幕的语音提问大约 1 到 2.5 分钱（一半以上是语音识别），每天问 20 次，一个月大约 6 到 15 元；这是按 2026 年 10 月 27 日各家的价格估的，算法在 GitHub 的说明里。

为什么装好后没有快捷键？

每台 Mac 的键盘不一样，顺手的键也不一样，所以默认不设。在「设置 → 快捷键」里选一个平时少用的键，比如右 Option、右 Command。

第一次打开提示「无法验证」怎么办？

Ask Free 有开发者签名，没有经过苹果公证。到「系统设置 → 隐私与安全性」底部点「仍要打开」，只需要一次。

Intel 芯片的 Mac 能用吗？

能。安装包是通用的，Apple 芯片和 Intel 芯片的 Mac 都能用，需要 macOS 14 或更新。

会自动更新吗？

会，从 1.2.0 起。每 6 小时到 GitHub 查一次新版本，有新版就在后台下好、核对签名，菜单栏里出「重启并更新」；不点的话，下次退出时装上。在主窗口「通用 → 更新」能关。装着 1.1.0 或更早版本的，要手动下载一次 1.2.0。

能用英文问吗？

能。说话问：火山引擎不指定语种时能认普通话和英语，也认粤语、上海话、闽南语、四川话、陕西话（按它的文档写的，没逐一实测）。打字问：DeepSeek 和千问读得懂的语言都行。问题是英文时，Ask Free 让它用英文答。软件界面只有中文。

截图会存下来吗？

会存在你自己的 Mac 上，回头在「历史」页能看到当时的画面；不会上传到别处，在「历史」页能删。

回答面板会打断我正在做的事吗？

不会。面板出现在屏幕右上角，不把你正在用的窗口挤到后面，正在打字的地方还在原处。

能换别的模型吗？

回答目前支持 DeepSeek 和阿里百炼千问，语音识别用火山引擎（豆包）。

隐私说明

更新于 2026 年 10 月 28 日，按 Ask Free 1.2.0 的代码逐条核对。

我们会给前 100 位用户免费额度，所以需要统计有多少人在用。统计是匿名的。你同意了才发，见下面「匿名使用统计」一节。

录音、问题和截图只在你按下提问键的时候发出去，直接发给你自己选的服务商，不经过我们；问过的问题和当时的截图只存在你的 Mac 上。另外只有两件事会连网：检查更新连 GitHub；你同意了的话，每天给我们的服务器发一次匿名统计。

我们是谁

Ask Free 是 SchaeferAnjon 个人做的开源软件，基于 kdsz001 的 Typefree 修改而来，以 GPL-3.0 发布，源码在 GitHub。软件只在你同意匿名使用统计以后，每天连一次我们的服务器（api.us-cloud.uk）报到，别的时候不连。

对这份说明有疑问，写邮件到 infoschaeferanjon@gmail.com，或者在 GitHub 提问题。

留在你电脑上的

  • API Key：存在 macOS 钥匙串里，不写进普通文件。
  • 设置：在 ~/.config/askfree/，这个文件夹只有你的账户能打开。同意匿名使用统计以后，这里多一个 usage-ping.json，记着那个随机编号和上次报到的日期。
  • 问答历史：每一轮的问题、回答和时间在 history.jsonl；这一轮真发给模型的两张截图（整屏的缩小图和指针附近的放大图），以及回答里找到的图的缩略图，在 history-images/。都在上面那个文件夹里，在「历史」页能看、能删。历史每一问都会记，1.2.0 还没有关掉它的开关。
  • 录音：不存。松开键后临时转一次格式，转完的临时文件马上删掉，再发给识别服务。
  • 运行日志：~/Library/Logs/AskFree.log，只记步骤和耗时（比如这一问有几个字、花了多少毫秒），不记问题、回答和截图。

什么时候发出去

只在你按住（或轻点）自己设的提问键说完的时候，或者用打字键提问的时候。平时不录音、不截屏，菜单栏图标也不会一直听着。

「看屏幕问」和「打字问」在按键那一刻截屏；「只提问，不看屏幕」那个键不截屏，只发语音转出来的文字。在主窗口「回答方式」页关掉「让 AI 看屏幕」，哪种问法都不截屏。

匿名使用统计

我们会给前 100 位用户免费额度，所以需要统计有多少人在用。统计是匿名的。

从 1.2.0 起，Ask Free 在欢迎引导里问你一次（更新上来的老用户在第一次打开主窗口时问），「同意」和「不用了」两个按钮一样大，哪个都没替你选好。只有点了「同意」才发；没回答、点了「不用了」都什么也不发。

同意以后，每天发一次，发给我们的服务器（api.us-cloud.uk），只有这几项：

  • 一个随机编号：第一次报到时随机生成，存在你的 Mac 上，只用来数人数，跟你的名字、邮箱和电脑硬件都没有关系。
  • 版本号、系统（macOS）和芯片类型（Apple 芯片还是 Intel）。
  • 用会员还是自带 Key（现在都是自带 Key），界面是什么语言。
  • 是哪个软件（Ask Free）。

不发你问的话、回答、录音、截图和 Key，不带账号或登录信息。服务器只按天存这几项，用来数每天有多少人在用；存下的统计里没有你的 IP 地址。

随时能改：主窗口「通用 → 隐私 → 匿名使用统计」，关掉以后什么都不发。开发者自己编的开发版不报到。

我们不做的

  • 不需要注册账号，也没有登录。
  • 没有崩溃上报、没有广告追踪；使用统计只在你同意以后发，而且是匿名的。
  • 没有中间服务器：录音、问题和截图不经过我们。
  • 不卖、不分享任何数据。

本网站

askfree.us-cloud.uk 是静态网页，放在 GitHub Pages 上，经 Cloudflare 和我们的服务器转发。网页不用 Cookie，不做访问统计。打开网页时，你的浏览器会向 GitHub 的接口（api.github.com）查一次最新版本号和文件大小；点下载时，文件由 GitHub 提供。这些服务照惯例会记访问日志（IP 地址、时间、浏览器），我们不拿它做统计。

怎么删掉

  1. 「历史」页右键一条删除，或者全部清空，当时的截图和找到的图一起删掉。
  2. 退出 Ask Free，删掉 ~/.config/askfree/ 文件夹（随机编号也在里面）和 ~/Library/Logs/AskFree.log。
  3. 打开「钥匙串访问」，搜索 askfree，删掉里面的 Key。
  4. 已经发给服务商的内容，按那一家的规定在它的控制台或客服那里处理。我们手上只有匿名统计，对不上是谁；不想再发，在「通用」里关掉匿名使用统计。
